# 使用说明

## 编辑与保存

首页“手动排版”创建空白文章。“继续编辑”打开当前文章；“草稿”可查找已保存的文章。

标题始终在编辑面板顶部。“内容”面板用于选择、增加、移动、移除区块和替换图片；“样式”面板用于主题、导语、署名、字号及间距。支持 PNG、JPEG、WebP，本地图片不超过8MB。

修改后约1秒自动保存，也可手动保存。切换或新建前会保存尚未写入的修改。草稿只保存在运行服务的电脑上，不会自动同步。

切到其他标签页时会立即尝试保存；还有未保存的修改时，刷新或关闭页面会由浏览器提醒。若显示“未保存 · 请重试保存”，请保留页面并重试，或在“导出”中下载 JSON 备份。浏览器崩溃或强制结束进程时不能保证出现提醒。

窄窗口通过“编辑 / 预览”切换工作区。文章预览支持手机和宽屏。工具界面样式与文章模板彼此独立。

## 导入、导出与备份

“更多 → 导入文稿”支持 TXT、简化 Markdown 和本项目 JSON。第一行作为标题，空行分段，Markdown小标题和引用可识别；不支持完整 Markdown、Word 或 PDF。

“导出”中可下载含图片的独立 HTML，或下载可再次导入的 JSON 备份。“复制 HTML”复制的是源代码。HTML 文件不等于公众号后台已保存，复杂布局进入其他编辑器后需要人工确认。

## 参考排版

输入公开 HTTPS 图文链接，或展开“其他参考方式”导入 HTML。可保留参考布局，也可套用开源主题。自己的文稿留空时使用当前文章；生成后另存新稿，保留原稿。

截图只用于人工对照，不自动识别。验证码、登录限制和动态内容可能影响读取；不要绕过平台验证。带有嵌套卡片、动画、SVG的结构不保证完整还原。

## AI 排版

配置服务地址、模型名和 API Key 后，输入排版要求。生成方案只调整层级和视觉，保留原文字及图片顺序；内容校验失败会拒绝采用。可以对比、继续调整、返回上一方案，采用时另存新稿。

每次最多12,000字；仅支持公网 HTTPS 的 Chat Completions 兼容服务。文稿和图片说明会发送到所选服务，图片二进制不会发送。真实模型效果受所选服务影响，本项目没有内置付费模型额度。

## 规范检查

内置的是从文字运营要求提炼的排版规则示例，不包含原始文档或人员名单。具体规则仍应由使用者确认。正文和署名分开检查，标题、图注与不确定区块默认保留；分类可以手动修改。

字号、行距、字距、对齐、颜色、缩进和连续正文空行可勾选修正。复杂卡片边距、标点语义、署名来源及卡片位置需人工复核。仅在秀米独立副本上修改，详见 [秀米接入](xiumi.md)。
