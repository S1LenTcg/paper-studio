# 已知限制

- 当前是本机个人工具；没有公网部署、多人权限、账号隔离或数据加密承诺。
- 自动测试、页面交互验证和真实云端/秀米验收是不同层次。测试通过不表示所有外部服务都兼容。
- AI支持结构化排版，不提供改写、事实核查、截图识别或配图生成。真实模型效果、费用及兼容性需用户自己的服务验证。
- 公开文章可能因登录、验证码、反爬或结构变化而无法读取。复杂CSS、动态装饰及嵌套布局不保证还原。
- 秀米依赖外部源码与浏览器页面实现细节，未固定可跨环境复现的上游版本；远端图片独立编辑能力需人工检查。
- 规范检查的自动保存完整流程尚待真实验收；复杂边距、标点语义、署名来源不自动处理。
- 版式示例页仅展示设计，未接入文章编辑或导出。
- 目前主要在 Windows 上验证。CI中的其他平台通过前，不声明相同程度的兼容性。

请通过仓库 Issues 提交可复现步骤。优先使用虚构文章；不要上传 Cookie、二维码、密钥或浏览器用户目录。
