# 秀米实验接入

本地编辑、预览和导出不依赖秀米。自动化适配不是官方开放接口；页面改版或账号状态变化可能导致失败。

## 可选安装

在已创建的虚拟环境中安装：

```bash
python -m pip install -e ".[xiumi]"
```

需要 Chrome，以及外部 [all-to-xiumi](https://github.com/hanselhan23/all-to-xiumi) 源码。该项目不随本仓库打包，需自行安装并确认其许可与依赖。

Windows PowerShell：

```powershell
$env:PAPER_XIUMI_SOURCE = '你的 all-to-xiumi 源码目录'
python -m paperstudio.server --open
```

macOS / Linux：

```bash
PAPER_XIUMI_SOURCE=/path/to/all-to-xiumi python -m paperstudio.server --open
```

适配器会检查依赖和所需函数；没有固定、跨环境验收的上游版本。本机曾有成功记录，但本机依赖包含任务期间的调整，不能保证直接克隆上游即获得相同结果。接入前应检查 [已知限制](limitations.md)。

## 发送文章

1. 点击“导出 → 发送到秀米新草稿”。
2. 在工具打开的专属 Chrome 窗口正常登录，验证码由用户处理。
3. 等待写入、保存前检查、保存和重新打开核对。
4. 在秀米人工确认视觉效果、换图、移动组件和长文效果。

只新建草稿，不覆盖现有稿件，也不向公众号发布。图片目前可能位于文本组件中，不能据“能显示”断言是可独立换图的原生图片组件。

## 检查现有稿

粘贴草稿编辑链接，先读取报告。确认各区块用途后选择修正项；工具核对原稿是否变化，通过秀米“另存一个图文”创建独立副本，再进行修改、保存与回读。

新检查适配器的真实登录→检查→另存→修正→保存→重开流程尚未完成端到端验收。单篇人工辅助操作成功和模拟浏览器测试均不能替代该验证。

## 登录与异常

- 日常浏览器的登录不会复制进来。只有主动勾选“记住本机登录”，才将专属资料保存在本机数据目录下。
- 再次使用同一专属登录目录前，关闭上一次工具窗口。
- 检查任务最多等待30分钟供确认；发送任务的登录等待最长10分钟。
- `uncertain` 表示另存或保存结果不明确，应先查看浏览器和记录，不要立即重发。
- 服务重启不会自动重试远端写入。创建草稿与保存后，仍需人工核对。
